# 优你家Plus App 截图目录

把 App 各模块的**实际截图**按下面文件名放入本目录即可，无需改代码。

## 文件命名（与 modules.json 对应）

| 文件名 | 模块 | 说明 |
|--------|------|------|
| `APP首页.png` | APP首页 | 默认展示页 |
| `蓝牙开门.jpg` | 蓝牙开门 | 无感开门/访客 |
| `物业服务.jpg` | 物业服务 | 公告/工单 |
| `物业缴费.jpg` | 物业缴费 | 物业/水电缴费 |
| `报事报修.png` | 报事报修 | 报修/进度 |
| `邻里圈子.jpg` | 邻里圈子 | 邻里互动 |
| `购好物.png` | 购好物 | 商城/拼团 |
| `优生活.jpg` | 优生活 | 家政预约 |
| `享到家.png` | 享到家 | 到家服务 |
| `优礼节.jpg` | 优礼节 | 会员礼遇 |

- 格式支持 `jpg` / `png`，建议竖屏手机截图（约 750×1624 或 1080×2340），比例越接近 9:19.5 越好看。
- 文件名改了但想换名字？改 `modules.json` 里的 `file` 字段即可。
- 想加 / 删模块？直接编辑 `modules.json` 的 `modules` 数组（增删条目）。`default` 为进入时默认展示的模块 id。

## 找不到图片时

若某模块图片缺失，手机会显示该模块名的占位界面（带模块色），不会报错。
